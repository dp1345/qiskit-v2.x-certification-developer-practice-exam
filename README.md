# Qiskit Certification Practice Exam

A collection of independently developed multiple-choice questions (MCQs) to help learners prepare for the **IBM Certified Quantum Computational Scientist — C1000-179: Fundamentals of Quantum Computing Using Qiskit v2.X Developer** certification.

## Project Overview

This project provides practice questions, answer keys, and technical explanations covering the eight IBM certification exam objectives.

Questions are independently authored using IBM Quantum documentation and the IBM certification study guide as technical references. They are not copied from official sample exams or third-party question banks.

## Contents

- `practice_exam_qiskit.md` — 30 original MCQs.
- `solution_qiskit.md` — Separate answer key with explanations and technical references.

## Topics Covered

1. Perform quantum operations.
2. Visualize quantum circuits, measurements, and states.
3. Create quantum circuits.
4. Run quantum circuits.
5. Use the Sampler primitive.
6. Use the Estimator primitive.
7. Retrieve and analyze circuit results.
8. Operate with OpenQASM.
